# MY SPACE · 个人导航页

一个轻量、无数据库、部署即用的个人导航主页。采用 **PHP + JSON** 实现，首页展示个人名片与常用链接，并附带**可视化后台**，可在线修改资料、上传头像、配置底部导航栏与分享文案。适合个人站长部署在 cPanel、虚拟主机等任意支持 PHP 的环境。

> 当前版本为安全加固版（v1.1）：已修复 XSS、CSRF、明文密码、恶意文件上传等漏洞，详情见文末「安全加固记录」。

---

## 功能特性

- 首页模块
  - 个人名片：头像 / 名字 / 身份标识 / 一句话简介 / 邮箱复制
  - 网址导航：10 类入口图标卡片，支持分类筛选与关键词搜索
  - 一键分享：调起系统分享（含 `{name}` 变量文案），不支持时降级为复制链接
  - 底部悬浮导航栏：回顶部 / 弹提示 / 跳转 / 拨号 / 发邮件，按钮全部后台可配
- 后台管理（`admin.php`）
  - 登录保护，默认密码 `admin888`，登录后请立即修改
  - 资料、头像（URL 或文件上传，支持 jpg/png/gif/webp）、导航入口增删改
  - 导航栏按钮增删改、分享标题/文案配置
  - 数据实时落盘 `myspace_data.json`，无需数据库
- 部署友好
  - 单目录即用，无 Composer / 无构建步骤 / 无外部依赖
  - 数据文件自动生成；`.htaccess` 已禁止直接下载 JSON 数据

## 快速部署

1. 将本目录所有文件上传到 Web 根目录（cPanel 为 `htdocs`，宝塔为 `wwwroot/站点目录`）；
2. 确保目录对 PHP 用户可写（后台需写入 `myspace_data.json`、创建 `uploads/`）；
3. 浏览器访问 `index.php` 查看首页，访问 `admin.php` 进入后台；
4. 登录后在后台「修改管理密码」处替换默认密码。

## 目录结构

```
.
├── index.php      # 前台首页（数据缺失时自动生成默认配置）
├── admin.php      # 后台管理页
├── .htaccess      # 数据保护 + 禁用页面缓存
├── README.md      # 本文档
└── uploads/       # 头像上传目录（后台自动创建，禁止执行脚本）
```

## 数据文件说明

- 站点数据统一存放于 `myspace_data.json`（默认生成在站点根目录）。
- 若希望数据放在 Web 根目录之外更安全，可手动将 `myspace_data.json` 移到网站根目录的**上一级目录**，程序会自动读取（`index.php` / `admin.php` 均支持）。
- 后台密码以 `password_hash`（bcrypt）哈希存储，不落明文。

## 常用自定义

## 安全加固记录（v1.1）

- 修复前台 XSS：服务端注入 JSON 增加 `JSON_HEX_TAG` 等转义；前端渲染统一经过 `esc()` HTML 转义；
- 修复 `javascript:` / `data:` 伪协议注入：前端 `safeUrl()` 协议白名单 + 后台保存时协议过滤；
- 修复底部导航按钮内联 `onclick` 注入：改为 `data-*` 属性 + 事件委托绑定；
- 后台增加 **CSRF Token** 校验（登录 / 保存 / 退出全覆盖）；
- 后台密码改为 `password_hash` 存储，兼容旧明文并自动升级；
- 头像上传改为 `getimagesize` 真实图片校验 + 随机文件名，且 `uploads/.htaccess` 禁止脚本执行；
- 链接 URL 保存时过滤 `javascript:` / `data:` / `vbscript:` 伪协议。
